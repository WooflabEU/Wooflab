# WooflabEU brand assets

[Project overview](../README.md) · [Deployment guide](../DEPLOYMENT.md)

The logo is a geometric W with two rounded troughs and a shorter central peak.
Its waveform-like shape connects the WooflabEU name with a workshop for digital
experiments. The organization name is written **WooflabEU**.

The SVG wordmark uses outlined Space Grotesk lettering, so it does not need an
installed font to render. The font's license is included in
[`licenses/space-grotesk-OFL.txt`](../licenses/space-grotesk-OFL.txt).

## Upload the GitHub organization avatar

1. Open the **wooflabEU** organization on GitHub.
2. Open **Settings**.
3. Under the organization profile picture, select **Upload new picture**.
4. Select `public/brand/wooflabeu-avatar.png` from the extracted project.
5. Keep the complete square image visible when cropping, then save it.

Uploading the source files to a repository does not change the organization's
profile picture; upload the avatar separately through organization settings.

GitHub's [organization profile documentation](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile#changing-your-organizations-profile-picture)
describes the upload controls. Its [profile picture reference](https://docs.github.com/en/account-and-profile/reference/profile-reference#profile-picture-requirements)
recommends about 500 × 500 pixels and requires a file smaller than 1 MB.

Use the supplied square avatar for GitHub. Use the horizontal logo when the
name needs to appear alongside the mark. Preserve the aspect ratio and the
clear space already present in each SVG view box.

The shared website header, footer, and favicon use the same W geometry.
The external icon sprite contains the reusable `wooflabeu` symbol. The existing
fictional character illustrations remain part of the website content.
